# zomato-dataset# Zomato Data Analysis

This project performs data cleaning, visualization, and animation on the Zomato dataset.

## Features
- Handling missing values
- Barplots and heatmaps using Seaborn
- Animated visualizations with Matplotlib
- Saved cleaned dataset and animation

## Folder Structure
- `data/`: Contains the cleaned Zomato CSV
- `visuals/`: Stores generated charts and animations
- `notebooks/`: Jupyter notebooks for EDA and plotting
